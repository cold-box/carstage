# Planning docs rules

- Docs are written in Korean. Sentences end with a predicate. No em dashes (—).
- Files stack in numbered order. Rather than rewriting an old version, write a new one (v2, v3) and note at the top of the old one what changed.
- Legal and business judgments carry source links and say they are not legal advice.
- Emulator verification results go in `docs/05-emulator-findings.md` with the date and the evidence (a log summary).
- When you add a doc, update the list in `docs/README.md`.
